# No Focus

Адаптивный веб-сайт с возможностью переключение светлой и темной темы.

## 📋 Описание проекта

**No Focus** - это адаптивный веб-сайт, посвященный проблемам концентрации внимания в современном мире. Проект демонстрирует профессиональный подход к веб-разработке с акцентом на семантическую верстку, доступность и современные CSS-технологии.

### 🎨 Ключевые особенности:
- **Темная и светлая темы** с автоматическим переключением
- **Адаптивный дизайн** для всех устройств
- **Семантическая разметка** для улучшения доступности
- **Современные CSS-технологии** (Grid, Flexbox, CSS-переменные)

## 🚀 Функциональность

### 🎭 Цветовые схемы
- **Автоматическое определение** темы системы
- **Ручное переключение** между темной и светлой темами
- **Плавные переходы** между состояниями
- **Корректное отображение** всех элементов в обеих темах

### 📱 Адаптивность
- **Mobile-first** подход
- **Резиновая верстка** между брейкпоинтами
- **Оптимизированные изображения** с lazy loading
- **Корректное отображение** на всех разрешениях экрана

### ♿ Доступность
- **Семантические теги** (header, main, footer, section, nav)
- **Правильная иерархия заголовков** (h1-h4)
- **Alt-тексты** для всех изображений
- **Фокус-индикаторы** для интерактивных элементов

## ⚙️ Технологический стек

### 📝 Frontend:
- **HTML5** - семантическая разметка
- **CSS3** - современные стили и анимации
- **JavaScript** - интерактивность и переключение тем
- **Flexbox/Grid** - современная верстка

### 🎨 Стилизация:
- **CSS Custom Properties** (переменные)
- **Методология БЭМ** для именования классов
- **Отдельные файлы** для тем (dark.css, light.css)
- **Глобальные стили** и переменные
